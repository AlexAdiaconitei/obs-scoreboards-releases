# OBS Scoreboards releases

Windows sports scoreboards controlled from a phone over LAN or Tailscale.

<p>

</p>

Download the Windows x64 installer from [Releases](https://github.com/AlexAdiaconitei/obs-scoreboards-releases/releases). Add its fixed overlay URL as a Browser source in OBS.

This repository contains release assets and the signed updater feed. Source code is maintained separately. Each release includes SHA-256 checksums. Updater signatures verify downloads inside OBS Scoreboards; Windows Authenticode signing is not configured.
